# Telegram YouTube 4K Bot

ربات خصوصی تلگرام برای دانلود YouTube Shorts در بالاترین کیفیت ممکن و ارسال در تلگرام.

## ویژگی‌ها

- فقط برای مالک ربات کار می‌کند
- ابتدا نسخه 2160p را دانلود می‌کند
- اگر فایل بزرگ‌تر از 50MB شد، فقط فشرده می‌کند
- رزولوشن را کاهش نمی‌دهد
- خروجی MP4 با H.265
- مناسب YouTube Shorts
- قابل اجرا روی Render رایگان

## راه‌اندازی

1. در BotFather یک ربات بساز و توکن آن را بردار.
2. آیدی عددی تلگرام خودت را پیدا کن.
3. این ریپازیتوری را در GitHub آپلود کن.
4. در Render یک Web Service از نوع Docker بساز.
5. ریپازیتوری را وصل کن.
6. این متغیرها را در Render اضافه کن:

```env
BOT_TOKEN=توکن_ربات
OWNER_ID=آیدی_عددی_تلگرام
